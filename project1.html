About the Project

UniFix is a predictive maintenance solution for campus facilities within Princess Nourah bint Abdulrahman University. The goal of the project is to create an intelligent prediction model that can detect future equipment failures based on maintenance history.

The project analyzes maintenance records to find behavioral trends and hidden patterns in equipment failure. It focuses on building a flexible AI model that can be integrated into an existing maintenance management system.

The system is designed to be scalable, adaptable, and useful for future expansion into other facility management platforms.
