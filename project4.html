About the Project

Hogwarts Adventure is a text-based interactive game built with React and TypeScript. It was designed to showcase storytelling, state-driven UI, dynamic logic, and user interactivity.

Players explore a mysterious world, make choices that affect the storyline, discover legendary items, and experience different parts of the game through interactive decisions.
